# CloudGuardAI
# IS350 – CloudGuard AI: Project Management

## Overview

CloudGuard AI is an academic project developed as part of the IS350 Project Management course. The project focuses on planning and managing the development of an AI-enhanced cloud threat detection system designed to improve security monitoring within AWS environments.

The proposed system enhances AWS GuardDuty by using Artificial Intelligence to classify security alerts, reduce false positives, verify IP addresses, and provide security teams with clear summaries and insights for more efficient threat monitoring.

## Objectives

- Improve the efficiency of cloud threat detection and monitoring.
- Use AI to classify security alerts as Normal, Suspicious, or Attack.
- Reduce the impact of false-positive alerts on security analysts.
- Provide a dashboard for alert prioritization and monitoring.
- Generate monthly summaries and statistical insights.
- Verify incoming IP addresses by identifying known and unknown IPs.
- Apply project management practices throughout the project lifecycle.

## Project Management Approach

The project follows the Incremental Model, allowing the proposed system to be planned and developed through separate increments.

The project management plan includes:

- Project Charter
- Requirements Analysis
- Project Scope Statement
- Work Breakdown Structure (WBS)
- WBS Dictionary
- RACI Matrix
- Gantt Chart
- Risk Register
